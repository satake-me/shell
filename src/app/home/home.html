Shell isolado carregando dois remotes externos

Este repositorio contem apenas o host. Ele consome mf1 e mf2 por URL, sem compartilhar o mesmo workspace ou repositorio com os remotes.

Fluxo local shell -> federation.manifest.json -> mf1/mf2 Suba os tres repositorios em paralelo para navegar entre os remotes.
@for (project of projects; track project.name) {

1. Suba os remotes

Execute npm start em ../mf1 e ../mf2.

2. Suba o shell

Execute npm start neste repositorio e abra http://localhost:4200.

3. Navegue pelas rotas
